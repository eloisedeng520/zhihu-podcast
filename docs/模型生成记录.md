# 模型生成记录

每期节目保存在 `episodes` 表的 `payload` 中，字段 `generationLog` 按调用顺序记录模型交互。服务端在调用模型时把完整提示词、JSON 输入和 JSON 输出写入日志，因此可以按 `stage` 区分三个阶段：

| 阶段 | `stage` | 输入 | 输出 |
|---|---|---|---|
| 理解观点 | `analyzing` | 知乎回答对象：标题、作者、链接、段落（含段落 ID；多答主时还包括 `contributors`） | `thesis`、`themes`、`limitations`。每个主题含标题、摘要和原文段落 ID |
| 编排对谈 | `writing` | 原文对象、理解阶段的 `outline`、节目时长 | `title` 和 `segments`。每段包含说话人、章节、文本类型及 `sourceIds` |
| 核对原文 | `reviewing` | 原文对象和生成的 `segments` | 每段一个 `checks` 结果，包含 `id`、`supported` 和 `reason` |

模型实际收到的 system prompt 由 `demo/server/providers.ts` 中的 `base`、图片规则和阶段指令拼接而成；user message 是对应输入对象的 JSON 字符串。模型被要求使用 JSON 格式返回。

每条日志结构如下：

```json
{
  "stage": "analyzing",
  "prompt": "完整的阶段指令（含通用 system prompt）",
  "input": { "...": "传给模型的 JSON" },
  "output": { "...": "模型返回的 JSON" },
  "createdAt": "2026-09-12T00:00:00.000Z"
}
```

在接口返回的节目对象中可直接查看 `generationLog`。生产环境不使用服务器本地文件系统（运行在 Cloudflare Worker），所以记录随节目 payload 持久化在 D1；需要下载到本地时，将该字段保存为 JSON 文件即可。

## 三个阶段的示例

下面示例使用缩短后的内容，仅展示字段结构。实际请求会传入完整原文和完整段落。

### 1. 理解观点（`analyzing`）

输入给模型的 JSON：

```json
{
  "title": "小时候经常给孩子挫折教育，能提高成年后的抗挫折能力吗？",
  "author": "示例作者",
  "url": "https://www.zhihu.com/answer/example",
  "paragraphs": [
    {"id": "p1", "text": "适度的困难能帮助孩子建立解决问题的经验。"},
    {"id": "p2", "text": "但故意制造羞辱和打击，可能损害孩子的安全感。"},
    {"id": "p3", "text": "关键在于困难是否适龄，以及是否有支持和复盘。"}
  ]
}
```

模型输出：

```json
{
  "thesis": "挫折经历可能提升抗挫能力，但效果取决于困难的强度、方式和支持环境。",
  "themes": [
    {
      "title": "适度困难带来应对经验",
      "summary": "孩子在可承受的挑战中练习解决问题，能够积累应对经验。",
      "sourceIds": ["p1"]
    },
    {
      "title": "羞辱式打击可能造成伤害",
      "summary": "把挫折教育变成羞辱或否定，可能削弱安全感，产生相反效果。",
      "sourceIds": ["p2"]
    }
  ],
  "limitations": [
    "原文没有给出统一适用的困难强度标准。",
    "结论依赖于孩子年龄、困难类型和成人支持方式。"
  ]
}
```

### 2. 编排对谈（`writing`）

输入给模型的 JSON：

```json
{
  "source": {
    "title": "小时候经常给孩子挫折教育，能提高成年后的抗挫折能力吗？",
    "paragraphs": [
      {"id": "p1", "text": "适度的困难能帮助孩子建立解决问题的经验。"},
      {"id": "p2", "text": "但故意制造羞辱和打击，可能损害孩子的安全感。"},
      {"id": "p3", "text": "关键在于困难是否适龄，以及是否有支持和复盘。"}
    ]
  },
  "outline": {
    "thesis": "挫折经历可能提升抗挫能力，但取决于方式和支持。",
    "themes": [
      {"title": "适度困难带来应对经验", "summary": "积累解决问题的经验。", "sourceIds": ["p1"]},
      {"title": "羞辱式打击可能造成伤害", "summary": "可能削弱安全感。", "sourceIds": ["p2"]}
    ],
    "limitations": ["需要考虑年龄、强度和支持方式"]
  },
  "minutes": 3
}
```

模型输出：

```json
{
  "title": "挫折教育，关键是怎么给",
  "segments": [
    {
      "speaker": "host",
      "chapter": "背景与主题",
      "text": "很多人相信，孩子小时候多经历挫折，长大后就更能扛事。问题是，什么样的挫折真的有帮助？",
      "kind": "transition",
      "sourceIds": []
    },
    {
      "speaker": "guest",
      "chapter": "适度困难带来应对经验",
      "text": "适度的困难，能让孩子在真实挑战里练习解决问题，慢慢积累应对经验。",
      "kind": "paraphrase",
      "sourceIds": ["p1"]
    },
    {
      "speaker": "host",
      "chapter": "边界与适用条件",
      "text": "那如果家长故意打击孩子，让他提前适应更大的压力呢？",
      "kind": "transition",
      "sourceIds": []
    },
    {
      "speaker": "guest",
      "chapter": "边界与适用条件",
      "text": "如果挫折变成羞辱和否定，反而可能损害孩子的安全感。关键还要看困难是否适龄，以及有没有支持和复盘。",
      "kind": "paraphrase",
      "sourceIds": ["p2", "p3"]
    }
  ]
}
```

### 3. 核对原文（`reviewing`）

输入给模型的 JSON：

```json
{
  "source": {
    "title": "小时候经常给孩子挫折教育，能提高成年后的抗挫折能力吗？",
    "paragraphs": [
      {"id": "p1", "text": "适度的困难能帮助孩子建立解决问题的经验。"},
      {"id": "p2", "text": "但故意制造羞辱和打击，可能损害孩子的安全感。"},
      {"id": "p3", "text": "关键在于困难是否适龄，以及是否有支持和复盘。"}
    ]
  },
  "segments": [
    {"id": "s1", "speaker": "host", "kind": "transition", "text": "什么样的挫折真的有帮助？", "sourceIds": []},
    {"id": "s2", "speaker": "guest", "kind": "paraphrase", "text": "适度的困难能让孩子积累应对经验。", "sourceIds": ["p1"]}
  ]
}
```

模型输出：

```json
{
  "checks": [
    {"id": "s1", "supported": true, "reason": "这是主持人的纯提问和串联语，没有加入事实断言。"},
    {"id": "s2", "supported": true, "reason": "与 p1 的含义一致，属于忠实改写。"}
  ]
}
```
