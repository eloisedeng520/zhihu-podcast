一个人维护爬七大平台的开源爬虫，看着头皮发麻又佩服
今天刷 GitHub 一眼瞅到 MediaCrawler，52.9k 星，一个国人扛七个平台反爬的开源社媒爬虫，小红书、抖音、快手、B 站、微博、百度贴吧、知乎全在里面，看着就头皮发麻又佩服。

三个让我眼睛一亮的点：

1. Playwright + CDP 模式默认走真实浏览器，直接复用你已经登录的 Chrome 登录态，省去手扫码和 cookie 续期那些破事，这招太鸡贼了
2. 不光抓帖子还能抓二级评论嵌套和创作者主页，关键词搜索、指定 ID 拉取、词云生成一条龙
3. 每个平台支持到哪一步在 README 特性表里一眼看完，不用翻代码猜

技术栈 Python 3.11 + Node 16 + Playwright，登录态全靠浏览器上下文续命，比硬模拟请求的爬虫稳一截。免责声明也写得清楚，仅供学习禁止商用，作者顺手列了几起真实爬虫违规案例提醒边界，国产开源里有这种自觉真心加分。

周末就拿它跑一批小红书奶茶店评论玩玩，做个情绪分布看看本地店都被怎么吐槽。
